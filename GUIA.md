# Firesport

Prototipo web móvil local. Abrir index.html desde un servidor HTTPS (GPS) o mediante localhost. No requiere instalación de dependencias. Datos guardados con localStorage, sin cuentas ni sincronización. El ranking y las invitaciones son demostraciones. Las fotos y los vídeos solo tienen vista previa temporal. Las rutas se dibujan esquemáticamente, el historial guarda métricas y no coordenadas. GPS solo en primer plano, sujeto a permisos. Los retos no se renuevan automáticamente.

## Vista web
El repositorio es privado. GitHub Pages para repositorios privados depende del plan; no cambiar visibilidad sin autorización. Si está disponible, configurar Settings > Pages > Deploy from a branch > main > / (root). También puede descargarse el repositorio y servirse localmente.
